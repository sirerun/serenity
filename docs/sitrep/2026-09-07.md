## Glossary for this report

- **pool session:** one of several Claude sessions working this plan in
  parallel, each claiming one task at a time so none of them duplicate work.
- **claim:** one session locking a task to itself in a shared file so no
  other session works it at the same time.
- **RFC acceptance criterion / AC / "gate":** the specific, testable
  requirement this project's founding design document sets for calling a
  milestone done — separate from, and stricter than, the plan file's full
  task list, which can include extra work beyond the strict requirement.
- **M0-M6 (milestones):** this project's six build phases plus a seventh,
  post-launch hardening phase (M6) that is explicitly excluded from "code
  complete."
- **"chief":** the peer Claude session on this machine that coordinates
  cross-session decisions across every project running on it, not just this
  one.
- **pull request:** a proposed code change; "merged" means it has actually
  landed in the shared codebase, not just been written.

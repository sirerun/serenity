## Glossary for this report

- pool session / work session: one of several independent work sessions
  this fleet runs in parallel, each claiming one task at a time so no two
  sessions duplicate the same work
- claim: one session locking a task to itself so no other session works
  on it at the same time
- wave: one batch of tasks dispatched together to run in parallel
- work area (also called an "epic" internally): a large body of related
  work made up of many smaller tasks — this plan has seven of them
- exit check (also called a "milestone exit" internally): a founder-run
  verification that a whole work area's promises actually hold on real
  data, gating whether later work areas are allowed to start
- conformance: proving that Serenity's implementation of a network
  protocol behaves exactly like the reference specification says it
  should, usually by replaying a fixed set of recorded test cases against
  it
- Sire: the separate product that is meant to embed this engine as its
  memory/reasoning layer

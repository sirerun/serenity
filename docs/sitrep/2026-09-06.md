## Glossary for this report

- **pool session:** one of several Claude sessions working the same plan in
  parallel, each claiming and finishing one task at a time.
- **claim:** one session locking a task to itself in a shared file so no
  other session duplicates the work.
- **chief:** the peer Claude session on this machine that has been managing
  machine-wide load and memory during this session's two resource incidents.
- **worktree:** an isolated, separate copy of the code a session works in so
  its changes don't collide with anyone else's.
- **M0-M6 (E0-E6):** the project's six build milestones plus a seventh,
  post-launch hardening phase (M6) that is explicitly not part of "code
  complete."
- **ladder:** the trust system that decides when an automatic action is safe
  enough to fire without asking a human first.
- **swap:** disk space the operating system borrows as extra memory when
  physical RAM is full; heavy swap use signals memory pressure.

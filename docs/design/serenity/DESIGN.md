# Serenity — collected calm

A warm, precise identity for personal memory: context that stays with its owner. The primary audience is developers using AI tools who repeatedly reconstruct decisions and project context. The homepage leads to installation, with documentation and source code one click away.

Signature: an open circular S made from two offset arcs. It suggests continuity without a sealed container. Warm paper and ink surround rose, lilac and ember glass surfaces from the supplied reference. LED type ties the physical texture to software.

Three checkable laws:
1. Product claims describe implemented behavior with source links; no invented performance metrics.
2. The three homepage cards preserve their internal proportions across widths.
3. Every product page offers installation, documentation, and a path to ask a question.

The user delegated direction selection. The supplied visual reference takes precedence over skill defaults against Inter, gradients and three cards. Deeper content and maker promotion require navigation and a footer, superseding the reference's single-file/no-extra-UI rule. The home stage remains viewport-sized on desktop; supporting pages scroll. Reduced motion uses poster images and removes decorative animation. Dark mode uses dark paper tokens on supporting pages; the reference stage retains its art direction.

Chat retains sire-chat's composer, underglow, bubbles, voice affordance, and restrained typography; only brand, content and backend configuration change. No signup or lead gate precedes installation.

# Website positioning — 8 September 2026

Serenity is the memory and context layer behind an agent or an integrating
system. The primary personal workflow is Codex CLI started in a separate
brain Git repository. The embedding workflow leaves the interface to the
calling application. A standalone Serenity Brain app is only a future
possibility. The website chat is a public documentation helper.

Sources reviewed:

- [Garry Tan’s gbrain](https://github.com/garrytan/gbrain): agent-operated
  memory and a brain owned by its user. Serenity’s inspiration and
  relationship to gbrain were confirmed by David in the copy brief.
- [Garry Tan: Own Your Intelligence](https://www.youtube.com/watch?v=eRrc1pUY5oU):
  English automatic captions retrieved with yt-dlp on 8 September 2026.
  Relevant passages: 05:34–07:46 (agents and owned context), 11:15–11:48
  (model, context, and harness), 14:26–15:12 (memory serving agents), and
  24:27–25:45 (start with an agent and a small library). Automatic captions
  contain recognition errors; the copy paraphrases rather than quotes them.

These sources establish inspiration, not Serenity feature parity with gbrain
or the talk’s examples. Published capability limits remain in the guides.

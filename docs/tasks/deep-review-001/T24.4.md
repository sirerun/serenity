## T24.4: Slug validator at the model boundary and the writer; reject per observation, not per batch

Findings: SEC-H03, FUN-03. Plan row: `docs/plans/deep-review-001-remediation.md`.

### Objective

A reviewer sees that a model-emitted subject can never become a file name or a raw YAML key: one strict validator (`domain.ValidSlug`, lowercase alphanumerics and hyphens, 1-64 chars) is applied when the extraction candidate is filtered, re-checked by the ingest path builder and the writer's publication path, and enforced by RenderEntity, which refuses rather than escapes; frontmatter is emitted by yaml.Marshal. One bad observation is dropped and counted; the rest of the batch proceeds.

### Scope

May create or modify:

- internal/domain/slug.go (new) and slug_test.go
- internal/extract/extract.go (filterCandidates: reject !ValidSlug(subject) or control chars in object)
- internal/ingest/batch.go (safePart -> domain.ValidSlug; snapshotObservations rejects per observation and returns the count)
- internal/ingest/review.go and internal/cli/sync.go (consume the per-observation rejection count instead of aborting)
- internal/writer/publish.go (publicationPath rejects control characters)
- internal/store/fence.go (RenderEntity refuses invalid slug or type; frontmatter via yaml.Marshal)
- the matching _test.go files

Out of scope:

- Quarantine of already-unparsable pages and the audit command (T24.5).
- Entity alias resolution semantics beyond rejecting an injected aliases key.

### Acceptance criteria

- [ ] domain.ValidSlug matches ^[a-z0-9](?:[a-z0-9-]{0,62}[a-z0-9])?$ and nothing else; a table test covers newline, colon, dot-segments, backslash, unicode and length 65.
- [ ] filterCandidates drops a candidate whose subject fails ValidSlug or whose object contains a control character, increments the rejected counter, and continues.
- [ ] snapshotObservations returns the safe subset plus a rejected count; sync logs the count and extracts the rest (FUN-03).
- [ ] RenderEntity returns an error for an invalid slug or type and never writes; frontmatter is produced by yaml.Marshal so a value containing a colon is quoted.
- [ ] publicationPath rejects any segment containing a control character.
- [ ] Reproduction test: the review's newline-subject payload is committed by nothing and the brain remains parsable afterwards.
- [ ] Genuine-red requirement: before the fix, add the new test and run it against the unchanged code; record the predicted failure output. Then apply the fix and record the green output. Both outputs go in the PR body.
- [ ] gofmt -l ./internal ./cmd ./pkg (empty), go vet ./..., golangci-lint run on the changed packages under the build lease.

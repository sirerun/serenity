## T24.11: CI supply chain: SHA-pinned actions, govulncheck and gitleaks jobs, dependabot, cosign signatures, SBOM, provenance

Findings: SUP-01. Plan row: `docs/plans/deep-review-001-remediation.md`.

### Objective

A reviewer sees a release pipeline at SLSA level 2 shape: every third-party action pinned to a commit, vulnerability and secret scanning on every pull request, dependency update PRs, and release artifacts that carry a cosign keyless signature, a CycloneDX SBOM and GitHub provenance attestation so `deploy.sh` can verify what it installs against something other than the same release's checksums.txt.

### Scope

May create or modify:

- .github/workflows/*.yml (pins, new jobs)
- .github/dependabot.yml (new)
- .goreleaser.yaml (sboms, signs, provenance)
- deploy/hosted/deploy.sh (cosign verify before install)
- docs/operator/ release verification note

Out of scope:

- Repository settings that need an admin (branch protection).
- Vendoring mcpoauth (deferred, T24.40).

### Acceptance criteria

- [ ] A test script under scripts/ (or actionlint plus a grep) fails if any `uses:` is not `owner/repo@<40 hex>` with a trailing `# vX.Y.Z` comment.
- [ ] govulncheck ./... and gitleaks detect run as required PR jobs; both are green on main at the merge commit.
- [ ] dependabot.yml: gomod weekly, github-actions weekly.
- [ ] .goreleaser.yaml: `sboms` (syft, cyclonedx) for every archive; `signs` with cosign keyless (`--oidc-issuer` GitHub) for archives and checksums; the publish job has id-token: write and attests provenance with actions/attest-build-provenance.
- [ ] deploy.sh verifies the downloaded archive with `cosign verify-blob` against the certificate identity of the release workflow before install; a tampered archive is refused (test with a modified byte).
- [ ] Genuine-red requirement: before the fix, add the new test and run it against the unchanged code; record the predicted failure output. Then apply the fix and record the green output. Both outputs go in the PR body. For this task the red run is the pin-check script failing on today's tag-pinned workflows.
- [ ] actionlint clean.

### Verification

```sh
actionlint
goreleaser check
goreleaser release --snapshot --clean --skip=publish,sign
```

## T24.22: Forget rewrites brain history to drop the fact path; force-with-lease push with a warning

Findings: PRIV-01 (history). Plan row: `docs/plans/deep-review-001-remediation.md`.

### Objective

A reviewer sees the third erasure target closed: under the writer lock, forget runs a path-scoped history rewrite through gitrun.Brain (`filter-branch --index-filter 'git rm --cached --ignore-unmatch <path>' -- --all`), expires the reflog, runs gc --prune=now, and the post-commit hook pushes with --force-with-lease and prints a one-line warning that other clones must re-clone. `serenity forget --help` and the operator docs state this.

### Scope

May create or modify:

- internal/writer/memoryfact.go (purge step), internal/writer/history.go (new rewrite helper over gitrun)
- internal/cli/gitx.go (hook: force-with-lease after a rewrite marker)
- internal/cli/forget.go help text; docs/operator/ forget page
- tests with a real repository fixture

Out of scope:

- Hosted brain deletion purge (T23.48).
- Compaction (E-compact) interaction beyond a regression test that compaction after a purge still works.

### Acceptance criteria

- [ ] After forget, `git rev-list --all -- <fact path>` is empty, `git reflog` has no entries referencing the old commits, and `git count-objects -v` shows the blob is gone after gc.
- [ ] The hook writes a rewrite marker; the next push uses --force-with-lease and the warning is printed once; without a marker the hook behaves as before.
- [ ] A brain with 1000 facts purges one fact in under 5 seconds on the mini (recorded in the PR).
- [ ] Compaction after a purge succeeds (regression).
- [ ] Genuine-red requirement: before the fix, add the new test and run it against the unchanged code; record the predicted failure output. Then apply the fix and record the green output. Both outputs go in the PR body.
- [ ] gofmt -l ./internal ./cmd ./pkg (empty), go vet ./..., golangci-lint run on the changed packages under the build lease.

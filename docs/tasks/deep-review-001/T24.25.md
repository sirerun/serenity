## T24.25: Provider requests use a system role and per-call nonce-delimited documents

Findings: AI-L04. Plan row: `docs/plans/deep-review-001-remediation.md`.

### Objective

A reviewer sees that a document cannot forge the prompt's own delimiters: instructions move to the system role on both providers, and untrusted documents are wrapped in delimiters that include a per-call random nonce the document cannot know.

### Scope

May create or modify:

- internal/router/anthropic.go, openai_compatible.go, request builders and tests
- internal/extract, internal/compose prompt builders (delimiter helper)

Out of scope:

- Prompt wording for extraction families (E1 evals).

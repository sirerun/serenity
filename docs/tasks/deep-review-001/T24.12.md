## T24.12: Redaction at the router chokepoint with widened key patterns and configurable rules

Findings: AI-02, PRIV-02. Plan row: `docs/plans/deep-review-001-remediation.md`.

### Objective

A reviewer sees exactly one place where text is redacted before it leaves the machine: the router applies redact.Apply to every Complete and Embed call for every provider; the pattern table covers the modern key shapes the review probed; `redact.patterns` in serenity.yml extends but cannot disable the built-ins; the threat model and the README describe this and disclose local egress.

### Scope

May create or modify:

- internal/redact/redact.go, redact_test.go (patterns table, fixture of synthetic keys)
- internal/router/router.go (chokepoint in Complete and Embed), router_test.go
- internal/compose/compose.go (remove the local call site)
- internal/config (redact.patterns)
- docs/threat-model.md (lines 49-66, 127-137 corrected)
- README provider section (egress disclosure)

Out of scope:

- Hosted dashboard disclosure (unchanged).
- Redaction of stored facts at rest (not the design; ADR 021).

### Acceptance criteria

- [ ] The fixture of eleven synthetic key shapes named in the review is fully redacted; the two legacy shapes still are.
- [ ] A router test with a recording provider proves the prompt and the embedding input reaching the provider are redacted for Anthropic, OpenAI-compatible and OpenRouter, for Complete and Embed.
- [ ] Removing the composer's own redact call changes no composer output (the chokepoint covers it).
- [ ] config: `redact.patterns` accepts named regexes; an invalid regex fails Load with the name.
- [ ] docs/threat-model.md no longer promises entity rules that do not exist; it describes the chokepoint and the config key.
- [ ] Genuine-red requirement: before the fix, add the new test and run it against the unchanged code; record the predicted failure output. Then apply the fix and record the green output. Both outputs go in the PR body.
- [ ] gofmt -l ./internal ./cmd ./pkg (empty), go vet ./..., golangci-lint run on the changed packages under the build lease.

## T24.7: internal/gitrun hardened git runner; migrate every local-product git call site

Findings: SEC-H05 (exec half), SEC-H04 (exec exposure). Plan row: `docs/plans/deep-review-001-remediation.md`.

### Objective

A reviewer sees one package that owns every git subprocess: `gitrun.Brain(dir)` for the brain the process owns (fsmonitor off, protocol.ext never, hooks kept so the auto-push hook still fires) and `gitrun.Foreign(dir)` for repositories the process does not own (additionally hooks off, global and system config ignored, read-only subcommands only); both scrub GIT_* from the environment except an allowlist. Every local-product call site uses it; hosted call sites are migrated by the hosted-completion tasks that own their files.

### Scope

May create or modify:

- internal/gitrun/gitrun.go, gitrun_test.go (new)
- internal/cli/gitx.go
- internal/connector/gitrepo/gitrepo.go (Foreign)
- internal/writer/commit.go, plan.go, dirtytree.go (Brain)
- internal/direction/publication.go, internal/supersede/publication.go (Brain)
- internal/import/gbrain/checkpoint.go (Foreign for the source, Brain for the target)

Out of scope:

- internal/hosted/pool/pool.go, internal/hosted/backup/backup.go, internal/hosted/gateway/lifecycle.go, internal/hosted/provision/canonical.go (hosted claims: T23.45, T23.49, T23.48, T23.46 migrate them; T24.30 adds the drift test afterwards).
- Changing any git subcommand's arguments beyond the hardening prefix.

### Acceptance criteria

- [ ] Brain adds -c core.fsmonitor=false -c protocol.ext.allow=never; Foreign adds -c core.hooksPath=/dev/null and sets GIT_CONFIG_GLOBAL=/dev/null, GIT_CONFIG_NOSYSTEM=1; both drop every GIT_* env var except GIT_SSH_COMMAND and GIT_TERMINAL_PROMPT=0 and keep PATH, HOME, LANG, TMPDIR.
- [ ] Test: a throwaway repository whose .git/config sets core.fsmonitor to a script that writes a marker file; running ls-files --others, status and diff through gitrun.Foreign and gitrun.Brain leaves no marker (reproduces the review's GIT_TRACE finding, then proves it closed).
- [ ] Test: the brain's post-commit hook still runs under gitrun.Brain (UC-040 regression).
- [ ] A package-level test greps the six local packages for exec.Command with a git argument and finds only gitrun.
- [ ] Genuine-red requirement: before the fix, add the new test and run it against the unchanged code; record the predicted failure output. Then apply the fix and record the green output. Both outputs go in the PR body.
- [ ] gofmt -l ./internal ./cmd ./pkg (empty), go vet ./..., golangci-lint run on the changed packages under the build lease.

### Verification

```sh
go test -race -count=1 ./internal/gitrun ./internal/cli ./internal/connector/... ./internal/writer ./internal/direction ./internal/supersede ./internal/import/...
```

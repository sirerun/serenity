## T24.6: git_repo connector: Lstat, regular-file check, symlink containment before every read

Findings: SEC-H04. Plan row: `docs/plans/deep-review-001-remediation.md`.

### Objective

A reviewer sees that crawling an attacker-supplied repository cannot read files outside it: every listed path is Lstat-ed, non-regular files are skipped with a counted reason, symlinks are resolved with EvalSymlinks and the resolved path must stay under the resolved repository top level, and only then is the file read.

### Scope

May create or modify:

- internal/connector/gitrepo/gitrepo.go (readContained helper used at the single read site)
- internal/connector/gitrepo/gitrepo_test.go (tracked-symlink fixture, nested-symlink fixture, regular-file regression)

Out of scope:

- The git exec hardening of the same connector (T24.7).
- index_only routing.

### Acceptance criteria

- [ ] readContained(toplevel, rel) returns an error naming the path for non-regular files and for any resolved path not prefixed by the resolved top level plus separator; Poll skips such entries and increments a skipped counter surfaced in the sync summary.
- [ ] Fixture: a repository tracking a symlink to a file in a sibling temp dir; Poll returns no source for it and the sibling file's bytes appear nowhere in the brain.
- [ ] Regular files under the repository are read exactly as before (existing tests unchanged).
- [ ] Genuine-red requirement: before the fix, add the new test and run it against the unchanged code; record the predicted failure output. Then apply the fix and record the green output. Both outputs go in the PR body.
- [ ] gofmt -l ./internal ./cmd ./pkg (empty), go vet ./..., golangci-lint run on the changed packages under the build lease.

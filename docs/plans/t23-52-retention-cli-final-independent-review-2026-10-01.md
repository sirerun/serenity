The source now treats Darwin `PermissionError` as an error whenever `leader_exited` is false; it does not wait for a later exit and reclassify the earlier EPERM. The SIGKILL path likewise only downgrades EPERM if WNOWAIT had already observed the exact leader exit before that signal attempt. In an isolated mutation, restoring the previous TERM and SIGKILL logic made both new regressions fail: the TERM control observed an incorrectly accepted EPERM, and the SIGKILL control detected a second, late `waitid` observation. Restored tests passed.

Cleanup now separates process-group status from reaping the owned child. After a group-signal failure, it rechecks exact child ownership with WNOWAIT and performs only a bounded wait of that child; ECHILD or mismatched ownership skips reaping. This preserves the operation failure and does not claim that descendants or the process group are gone. The new tests cover bounded reap after an owned-child signal error and no reap when waitid reports lost ownership.

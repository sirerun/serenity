Choose your install

Your everyday interface is Codex CLI running in your brain repository, or a system that integrates Serenity. The commands below install and verify the memory layer. There is no standalone Serenity Brain app today.

Serenity is early software for macOS on Apple silicon and Linux on amd64 or arm64. It requires Git and an accessible operating-system keychain. Start with a small set of notes.

Release or current source?

The latest packaged release is v0.1.1. The guides on this site describe current source, which includes newer commands. Use the source install below for these guides, or consult the documentation at your release tag.

Current source · Go 1.26+

Install from the main branch to use the workflows documented here:

GOWORK=off go install github.com/sirerun/serenity/cmd/serenity@main
serenity --help

Make sure your Go binary directory is on PATH. Run go env GOBIN; if it is empty, use the bin directory under go env GOPATH.

Packaged release · Homebrew

brew install sirerun/tap/serenity
serenity --help

Homebrew installs the released version, which may not include the latest source workflows.

Download a binary

Choose your platform on GitHub Releases ↗. Download the matching archive and checksums.txt, verify the archive checksum, extract it, and place serenity on PATH. Windows and Intel macOS are not packaged targets.

Give your agent a brain

Create a separate brain repository, verify its sources, then start Codex CLI there. For another system, choose the documented CLI, MCP, HTTP, or embedded interface.

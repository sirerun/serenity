Website and chat privacy.

This public website helps you understand and install Serenity. It is separate from any personal brain you create.

The website

Pages are static HTML, CSS and JavaScript hosted on GitHub Pages. Hosting and asset providers receive ordinary connection information when your browser requests content. The landing page loads background media from the supplied CloudFront hosts and fonts from Google Fonts.

The adoption chat

The chat is intended for questions about public Serenity documentation. Submitting a question sends its text and the recent conversation to the Serenity chat service on AWS Lambda. Model-assisted answers send that question, recent conversation, and relevant public documentation to OpenRouter and its selected model provider. If a model answer is unavailable, the chat labels its response as documentation search.

Do not submit passwords, API keys, confidential source material, or personal brain contents. The website chat does not have access to your local Serenity installation.

The chat keeps the conversation in browser memory for the current page session, not persistent browser storage. The service does not store conversation transcripts. Rate limiting stores a salted hash derived from the visitor IP and request counts with an expiry of approximately 25 hours; AWS TTL removal is asynchronous. Hosting and model-provider operational records and retention policies still apply.

Browser storage and controls

Chat theme preferences may be stored in your browser. Microphone input, when supported, begins only after you activate the voice control and grant browser permission. Your browser’s speech recognition service may process audio remotely.

Questions

For product issues, use the GitHub issue tracker with sanitized examples. For work with the creator, visit ndungu.dev.

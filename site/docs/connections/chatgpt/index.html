ChatGPT

All documentation

ChatGPT supports remote MCP apps with OAuth. Serenity now provides that flow; ChatGPT qualification is pending.

Connection settings

ChatGPT’s documented MCP authentication choices are OAuth, no authentication, and mixed authentication. Serenity supports the OAuth choice: dynamic client registration, PKCE, browser sign-in, and a consent page where you choose one brain and read-only or read-and-write access. Use https://serenity.sire.run/mcp as the server URL. No client ID or secret is required.

Do not choose “No Authentication” or put a bearer token in the server URL. That does not make this private endpoint compatible.

Qualification pending

This page does not walk through ChatGPT’s connector settings, because Serenity has not yet completed a remember-and-recall test through ChatGPT. Availability also depends on your ChatGPT account and workspace settings. If you try it, your connection appears under Connected agents, where you can disconnect it at any time.

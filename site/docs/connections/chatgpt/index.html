All documentation

ChatGPT supports remote MCP apps. Serenity still needs account linking.

Not ready to connect yet

ChatGPT’s documented MCP authentication choices are OAuth, no authentication, and mixed authentication. Hosted Serenity requires a private bearer token on every MCP request and does not yet implement OAuth. The dashboard token is not an OAuth client secret.

Do not choose “No Authentication” or put your token in the server URL. That does not make this private endpoint compatible.

What remains

Serenity needs an OAuth authorization and consent flow, secure token lifecycle, and end-to-end ChatGPT qualification before this guide can offer a Connect button. Availability also depends on your ChatGPT account and workspace settings.

For a token-based OpenAI coding client today, see the Codex guide.

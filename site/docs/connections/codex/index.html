In Your project memories, choose the brain to connect and create a token. Keep the token in private client settings or a secret environment variable; never commit it or paste it into a conversation.

Add the remote server

Merge this into the project’s .codex/config.toml. Load SERENITY_TOKEN privately into the environment that launches Codex, and trust the project so its configuration can load.

[mcp_servers.serenity]
url = "https://serenity.sire.run/mcp"
bearer_token_env_var = "SERENITY_TOKEN"

Check /mcp in Codex. Select a different brain token when switching to a project that should have separate memory.

Try your first memory

Restart or reconnect your harness, then ask: “Use Serenity to remember that this project’s test word is amber heron.” Next ask: “Use Serenity to recall this project’s test word.” Check the tool results. A successful connection alone does not verify a saved memory.

Serenity does not automatically ingest your repository or chat history. Your agent must use its memory tools. Writes use the configured embedding provider.

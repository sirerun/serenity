Serenity now offers the OAuth flow that Claude’s web products require. End-to-end qualification is still pending.

Claude.ai custom connectors

Serenity provides standard MCP OAuth: dynamic client registration, PKCE, browser sign-in, and a consent page where you choose one brain and read-only or read-and-write access. A custom connector that accepts a remote MCP server URL should use https://serenity.sire.run/mcp with no client ID or secret.

This page does not walk through Claude’s connector settings, because Serenity has not yet completed a remember-and-recall test through a Claude.ai connector. Availability also depends on your Claude plan and organization settings. Once you connect, the agent appears under Connected agents, where you can disconnect it at any time.

Claude Code cloud

Claude Code cloud supports MCP connections. Serenity has not yet qualified either the OAuth flow or a private environment-secret token in a cloud session. Do not assume your local MCP configuration or environment variables are copied into a web session.

Use the local Claude Code guide today. Cloud qualification still needs network access and a successful remember-and-recall test.

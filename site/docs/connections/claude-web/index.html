Bring your project memory into Claude with a custom connector. Sign in to Serenity and choose which memory Claude can use.

Add Serenity to Claude

  1. Open Customize → Connectors in Claude. Some versions show this under Settings.
  2. Choose Add → Add custom connector, then name the connector Serenity.
  3. Enter https://serenity.sire.run/mcp as the remote MCP server URL. Leave the advanced OAuth client ID and secret empty.
  4. Choose Connect. Sign in to Serenity using your email link if needed.
  5. Select a project memory and choose read-only access, or read-and-write access if you want Claude to save and forget memories. Approve the connection to return to Claude.

Serenity uses dynamic client registration and PKCE. You do not need to generate or paste a manual bearer token.

Check the connection

Enable Serenity in your Claude conversation. With read-and-write access, ask: “Remember that my test project is called Amber Heron.” In a new conversation with Serenity enabled, ask: “What is my test project called?” Check that Claude actually uses the Serenity tools.

You can review and revoke access from Connected agents. Each connection is limited to the project and permissions you approved.

If Add custom connector is disabled

Check your Claude account and workspace settings. Connector availability can depend on your plan or administrator. A disabled control in Claude cannot be fixed by changing your Serenity token.

Claude Code cloud

Claude Code cloud supports MCP connections. Serenity has not yet qualified either the OAuth flow or a private environment-secret token in a cloud session. Do not assume your local MCP configuration or environment variables are copied into a web session.

Use the local Claude Code guide today. Cloud qualification still needs network access and a successful remember-and-recall test.

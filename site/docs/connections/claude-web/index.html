Cloud sessions and local Claude Code have different connection paths.

Claude Code cloud

Claude Code cloud supports MCP connections, but Serenity has not yet qualified its token setup in a cloud environment. Do not assume your local environment variables or private MCP configuration are copied into a web session.

Use the local Claude Code guide for token setup today. Cloud qualification still needs a private environment-secret configuration, network access, and a successful remember-and-recall test.

Claude.ai custom connectors

Serenity does not yet provide an OAuth account-linking flow. A connector setup that requires OAuth cannot use a dashboard bearer token instead. This route is not available as a verified Serenity connection yet.

In Your project memories, choose the brain to connect and create a token. Keep the token in private client settings or a secret environment variable; never commit it or paste it into a conversation.

Connection settings

Transport
Streamable HTTP
Endpoint
https://serenity.sire.run/mcp
Authentication
Authorization: Bearer YOUR_TOKEN

Use your client’s remote MCP settings to supply this endpoint and header. For an application you build, use an MCP SDK’s Streamable HTTP client and load the token from your backend secret store. Follow MCP initialization and session handling; this is not a REST memory API.

The client must support custom authorization headers. Direct browser JavaScript requests are not supported; keep credentials on your application’s server. OAuth-only clients cannot connect yet. Clients that only support local stdio need a compatible adapter, which this hosted guide does not qualify.

Try your first memory

Restart or reconnect your harness, then ask: “Use Serenity to remember that this project’s test word is amber heron.” Next ask: “Use Serenity to recall this project’s test word.” Check the tool results. A successful connection alone does not verify a saved memory.

Serenity does not automatically ingest your repository or chat history. Your agent must use its memory tools. Writes use the configured embedding provider.

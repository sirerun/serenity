Choose what your agents share

Each brain is a separate memory space. Connect several harnesses to one brain when they should share context. Use different brains and their own tokens when projects should stay separate. A server name or repository folder alone does not isolate memory.

The free plan includes one brain; additional brains depend on your plan. Creating another token for the same brain does not create another memory space.

How OAuth connections work

Add https://serenity.sire.run/mcp to your agent. It opens a browser tab where you sign in to Serenity, choose one project memory, and approve read-only or read-and-write access. Access tokens are short-lived and renewed automatically with rotating refresh tokens. Each connection expires after 30 days, and you can disconnect any agent from Connected agents.

Choose what your agents share

Each brain is a separate memory space. Connect several harnesses to one brain when they should share context. Choose different brains during consent when projects should stay separate. A server name or repository folder alone does not isolate memory.

The free plan includes one brain; additional brains depend on your plan. Connecting another agent to the same brain does not create another memory space.

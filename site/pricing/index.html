What preview means

Hosted reliability, semantic retrieval and billing qualification are still in progress. Use non-sensitive test memories for now. Paid pricing and allowances shown here are planned, not a purchase offer.

Limits apply across all project memories in your account. Input tokens are counted for writes and recall queries. Storage includes memory history. If an enforced allowance is reached, the service rejects the affected operation; there are no automatic paid overages in this preview.

Choose your agent

Setup guides are available for Claude Code, Codex, Rakazo and other clients that support authenticated HTTP MCP. ChatGPT account linking is not ready; Claude cloud setup is not yet verified. Check your harness guide →

Your memory stays under your control

Choose which agents receive a project’s token. Export memory, revoke connections, or delete your account from the dashboard. Different tokens for the same project share its memory.

Memory writes and recall queries use the configured embedding provider. Forgetting removes a fact from current retrieval; earlier content can remain in Git history. Account deletion has a separate backup retention window. Read the privacy details.

Prefer to run it yourself?

Serenity is also open source. Install and operate it on your own machine or infrastructure. You manage hosting, backups and any model-provider charges.
